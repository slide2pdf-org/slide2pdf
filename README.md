# 📄 Slide2PDF India

An open-source, 100% client-side, and privacy-first online tool to convert images to PDF and PDFs to images instantly. No server uploads—everything is processed locally on your device.

🚀 **Live Website:** [https://slide2pdf-org.github.io/slide2pdf/](https://slide2pdf-org.github.io/slide2pdf/)

---

## ✨ Features
- 🔒 **100% Private:** Your files never leave your browser/device.
- ⚡ **Fast & Offline Compatible:** Powered by client-side JavaScript.
- 🎯 **No Registration:** Completely free to use with zero limits.
